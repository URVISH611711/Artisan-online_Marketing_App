# Artisan-AI — pgAdmin 4 Setup & Database Administration Guide

This guide explains how to administer the PostgreSQL database for Artisan-AI using pgAdmin 4.

## 1. Initial Setup

1. Open pgAdmin 4.
2. In the left browser pane, right-click **Servers** > **Register** > **Server...**
3. **General Tab:** Name it "Artisan-AI Local"
4. **Connection Tab:**
   - Host name/address: `localhost`
   - Port: `5432`
   - Maintenance database: `postgres`
   - Username: `postgres`
   - Password: `postgres` (or your local postgres password)
5. Click **Save**.

## 2. Creating the Database

1. Expand the newly created server.
2. Right-click **Databases** > **Create** > **Database...**
3. **Database:** enter `artisan_ai`.
4. Click **Save**.

## 3. Running the Schema / Migrations

You have two options to create the tables in `artisan_ai`:

**Option A: Using Alembic (Recommended)**
1. Ensure your `.env` has: `DATABASE_URL=postgresql://postgres:postgres@localhost:5432/artisan_ai`
2. Run `alembic upgrade head` from the backend directory.

**Option B: Using the generated SQL file**
1. In pgAdmin, right-click the `artisan_ai` database and select **Query Tool**.
2. Open the file `backend/schema.sql` (generated by `generate_schema.py`).
3. Paste the contents into the Query Tool and press `F5` (or click the Execute Play button).

## 4. Viewing Tables and Relationships

1. Navigate to: `Servers` > `Artisan-AI Local` > `Databases` > `artisan_ai` > `Schemas` > `public` > `Tables`.
2. You will see tables like `users`, `products`, `orders`, etc.
3. Right-click a table (e.g., `products`) and select **View/Edit Data** > **All Rows** to view the data.
4. To view relationships, right-click `artisan_ai` and select **ERD For Database**. This visualizes the schema connections.

## 5. Checking Constraints and Indexes

1. Expand a table in the left pane (e.g., `products`).
2. Expand **Constraints** to see primary keys, foreign keys, and unique constraints.
3. Expand **Indexes** to see custom B-Tree indexes created (e.g., `ix_products_status`).

## 6. Seed Data Execution

Once the schema is created, populate it with development data:
1. Open terminal in the `backend` directory.
2. Run `python seed.py`.
3. Go back to pgAdmin, refresh the `users` table, and you will see the mocked Artisan and Buyer profiles.
